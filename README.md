# 🏰 Wizarding Scapes — Lâu Đài & Khuôn Viên Hogwarts 77,777 Màn

Bộ đôi game giải đố **Match-3 Hardcore 77,777 màn** kết hợp cải tạo **2.5D Isometric** lấy cảm hứng từ thế giới phù thủy Harry Potter (Playrix Homescapes & Gardenscapes mechanics):

- **🏰 Lâu Đài Hogwarts (`homescapes`)**:
  - **Chương 1 biến đổi động theo 4 Nhà Hogwarts** (*Gryffindor*, *Slytherin*, *Ravenclaw*, *Hufflepuff*) với 4 bối cảnh 2.5D riêng, Giáo sư Chủ nhiệm riêng và nội thất mặc định theo tông màu Nhà.
  - 12 Chương × 9 vị trí cải tạo (108 hạng mục × 3 phong cách), Hầm Ngục Gringotts rút chốt vật lý, Siêu Xoay Thời Gian 2 màu & Thư Sấm 2×2.
- **🌿 Khuôn Viên Hogwarts & Rừng Cấm (`gardenscapes`)**:
  - 12 Khu vực × 9 cổ vật trang trí (108 hạng mục × 3 phong cách), Siêu Thần Hộ Mệnh Patronus, thời tiết Ngày / Đêm Trăng / Tuyết & âm thanh đa âm.
- **🦉 Hội Nhà Online (`/api/*`)**:
  - Đua Cúp 4 Nhà, Chat trực tuyến, tặng Tim & Thẻ Ếch Sô-cô-la, và **Độn Thổ Thăm Lâu Đài / Khuôn Viên 2.5D của bạn bè** theo mã định danh (`HW-DRACOM`, `HW-LUNALV`, `HW-CEDRIC`, `HW-HERMIO`...).
- **⚡ Siêu nhẹ (WebP + Gzip/Brotli + On-Demand Streaming)**:
  - 100% ảnh `.webp` nén tối ưu + nạp theo ngữ cảnh, đóng gói sẵn `.gz` / `.br` khi build và hỗ trợ cài đặt WebApp (PWA).

## Chạy thử tại máy

```bash
npm install
npm run build
npm run server   # http://127.0.0.1:5180 (Full Online + Static Gzip/Brotli)
```
